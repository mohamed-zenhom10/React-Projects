#  React Quiz App

A simple and interactive Quiz Application built with React.  
The app allows users to answer multiple-choice questions, track their score, and complete the exam within a limited time.

---

##  Features

- Display multiple-choice questions
- Highlight correct and wrong answers after selection
- Score tracking system (points system)
- Global exam timer (10 minutes)
- Progress tracking (question counter + progress bar)
- Navigation between questions
- Final result screen after finishing the quiz

---

## Tech Stack

- React.js
- React Router DOM
- Context API (for state management)
- CSS (custom styling)

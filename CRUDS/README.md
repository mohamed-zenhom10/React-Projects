# 📦 Product Management System (React CRUD App)

A professional **Product Management System** built with **React.js** that allows users to create, read, update, delete, and search products.  
The project uses **localStorage** for data persistence.

---

## 🚀 Features

- ➕ Add new products
- ✏️ Update existing products
- ❌ Delete products
- 🔍 Search products by:
  - Title
  - Category
- 💾 Data stored in **localStorage**
- 🔄 Automatic total calculation
- 📱 Responsive design (if styled)

---

## 🛠️ Technologies Used

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **LocalStorage**
